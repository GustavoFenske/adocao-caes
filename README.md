# 🐶 Adoção de Cães

Página web desenvolvida para simular uma plataforma de adoção de cachorros.

## 📌 Sobre o projeto

O projeto apresenta uma interface voltada à simulação de um sistema de adoção de cães, permitindo apresentar informações sobre os animais disponíveis.

## 🛠️ Tecnologias

- HTML5
- CSS3

## 🎯 Objetivo

Praticar a criação e estilização de interfaces web utilizando HTML e CSS.

## 🚀 Como executar

Abra o arquivo HTML em um navegador.
